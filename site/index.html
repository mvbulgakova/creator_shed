Конструктор расписания матфака

Расписание собрано из восьми опубликованных PDF. Программа нашла накладки и предложила два исправленных варианта: бережный и с полной перестройкой. Выберите вариант и посмотрите неделю любой группы, преподавателя или аудитории.

Сравнение вариантов

Пары считаются за две недели (1-я и 2-я). Занятия по отдельным датам, практики и дни самостоятельной работы не двигаются.

      Свободные аудитории

      «Поток до N групп» — сколько групп максимально сидело в аудитории по расписанию; ПК — компьютерный класс.
      Как это работает

      Идея взята у школьного «СуперЗавуча» с Хабра. Там расписание собирается имитацией отжига. Здесь тот же подход, только для вуза: потоки из нескольких групп, подгруппы, числитель и знаменатель, разные корпуса, занятия по отдельным датам.

      Разбор PDF. Из таблиц достаются ячейки вместе с их границами. Объединённая по горизонтали ячейка становится потоком из нескольких групп, по вертикали — занятием на обе недели. Из текста ячейки берутся дисциплина, тип занятия, преподаватели с подгруппами, аудитории, даты и дистанционный формат.

      Оптимизация. Занятия переставляются по дням, парам и неделям, аудитории меняются. Ход принимается, если штраф уменьшился, а иногда и при росте штрафа, пока «температура» высокая. Накладки преподавателей, групп и аудиторий штрафуются очень сильно. Окна, перегруженные дни, поздние пары, суббота, физкультура на Кибальчича сразу после пары на Краснопрудной и новые рабочие дни преподавателей штрафуются умеренно.

      Пожелания («у Цыбули Л.М. нет пар по субботам», «не трогать занятия Атанасяна С.Л.») и веса штрафов задаются в config.toml.

      python -m raspisanie parse            # PDF → data/parsed.json
python -m raspisanie check            # накладки и метрики действующего расписания
python -m raspisanie solve --mode gentle
python -m raspisanie solve --mode full --out data/optimized_full.json
python -m raspisanie export           # Excel и .ics для групп и преподавателей
python -m raspisanie site             # эта страница
