# Конструктор расписания ИМИ МПГУ

Вузовская версия «СуперЗавуча» ([статья на Хабре](https://habr.com/ru/articles/1089006/)) для Института математики и информатики МПГУ.
Программа читает опубликованные PDF-расписания, ищет накладки и пересобирает расписание имитацией отжига.

## Что умеет

* **Разбирает PDF расписания ИМИ** (`data/pdf/`). Учитывает объединённые ячейки: поток из нескольких групп, занятия на обе недели (числитель и знаменатель), подгруппы, параллельные дисциплины по выбору (Д/В 1.1 и 1.2), иностранные языки, дистанционные занятия (el.mpgu.su), физкультуру на Кибальчича, занятия по датам («по 14.10», «с 31.10», «12.09, 19.09»). Если ячейка разорвана переносом страницы, части склеиваются.
* **Проверяет действующее расписание**: накладки преподавателей, групп и аудиторий, окна, перегруженные дни, поздние пары, субботы, переезды на физкультуру.
* **Оптимизирует** в двух режимах:
  * `gentle` — бережная правка: убрать накладки и переезды, перенеся как можно меньше занятий;
  * `full` — полная перестройка подвижных занятий ради окон и поздних пар.
* **Выгружает** Excel (сетка по курсам) и календари `.ics` для каждой группы и каждого преподавателя (с учётом чётности недель и дат).
* **Собирает веб-страницу** `site/index.html`. На ней можно сравнить варианты, посмотреть неделю группы, преподавателя или аудитории, найти накладки, переносы и свободные аудитории.

## Запуск

```bash
pip install -r requirements.txt
python -m raspisanie parse                    # PDF -> data/parsed.json
python -m raspisanie check --date 2026-10-05  # проверка действующего расписания
python -m raspisanie solve --mode gentle      # -> data/optimized.json
python -m raspisanie solve --mode full --iters 600000 --restarts 2 --out data/optimized_full.json
python -m raspisanie export                   # out/raspisanie.xlsx, out/ics/*.ics
python -m raspisanie site                     # site/index.html
```

По умолчанию берутся группы, у которых на указанную дату (по умолчанию на сегодня) идут занятия по сетке. Флаг `--all` берёт все группы.

## Настройка

Веса штрафов, лимит пар в день и список занятий, которые нельзя двигать, задаются в `config.toml`. Там же пожелания преподавателей:

```toml
[teachers."Цыбуля Л.М."]
unavailable = ["сб", "пн 1"]      # когда не может

[teachers."Атанасян С.Л."]
available = ["вт", "чт 1-3"]      # может только в эти дни и пары
```

## Как устроено

| Модуль | Что делает |
|---|---|
| `raspisanie/pdfgrid.py` | таблицы PDF → ячейки (день, пара, недели, группы); подписи дней и времени в PDF повёрнуты, поэтому распознаются по набору символов |
| `raspisanie/lesson_text.py` | текст ячейки → дисциплина, тип (ЛК/ПЗ/лаб/ПР), преподаватели, подгруппы, аудитории, даты |
| `raspisanie/model.py` | события расписания, группы, склейка потоков между секциями PDF |
| `raspisanie/solver.py` | целевая функция и имитация отжига (ходы: перенос, обмен двух пар группы, смена аудитории, смена недели) |
| `raspisanie/export.py` | Excel и iCalendar |
| `raspisanie/site.py`, `site_template.html` | веб-просмотрщик |

**Потоки.** Одну и ту же лекцию преподаватель может читать сразу нескольким группам своего курса в одной аудитории. Это не накладка: оптимизатор может собирать такие лекции в поток, если группы помещаются в аудиторию (вес `stream_bonus`). Лекции с одинаковым названием на разных курсах в поток не объединяются.

Жёсткие ограничения (накладки, лабораторная не в компьютерном классе, поток не помещается в аудиторию, преподаватель недоступен) штрафуются очень сильно. Мягкие ограничения — окна у групп и преподавателей, поездка преподавателя в корпус ради одной пары (дни только с дистанционными парами не считаются), число рабочих дней преподавателя, больше четырёх пар в день, день ради одной пары, пары после 16:00 и в субботу у очников, физкультура на Кибальчича вплотную к паре на Краснопрудной, новый рабочий день преподавателя. Вместимость аудиторий оценивается по самому большому потоку, который в ней сидел. Компьютерные классы — аудитории, где в основном проходят лабораторные.

Чётность недель привязана к датам из PDF: 1-я неделя начинается 31.08.2026, 14.09 и 28.09 тоже 1-я неделя, 09.09 — 2-я.

Занятия по датам, практики и дни самостоятельной работы считаются закреплёнными. Конфликт с занятием по датам помечается как «возможный»: по PDF нельзя понять, пересекаются ли даты.
